# SaaS Think Tank for Cursor

SaaS Think Tank publishes independent, evidence-backed research across the SaaS industry. Compare software and see the sources, dates, and limits behind each finding. [SaaS Think Tank software research](https://saasthinktank.com/)

The current plugin connects to a public dataset with 16 findings on Bubble, Lovable, Base44 and Replit. It covers source code export, GitHub sync, external backends and built-in databases. [App builder research behind this edition](https://saasthinktank.com/ct/no-code-ai-app-builders/)

Try asking Cursor **“Compare Bubble and Lovable on source code export. Show what can leave each platform, the plan conditions, the dates checked and the sources.”**

The plugin's three tools search, retrieve and compare findings. The connection is read-only and requires no account. If a product or question is outside the dataset, the server reports that limitation.

For a local installation, copy this directory to `~/.cursor/plugins/local/saas-think-tank`, reload the Cursor window and open **Customize**. Then confirm the SaaS Think Tank server is available. See [Cursor's local plugin instructions](https://cursor.com/docs/plugins#test-plugins-locally).
